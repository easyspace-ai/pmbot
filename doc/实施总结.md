#### 1. 最小订单大小处理
**文件**: `internal/oms/oms.go`

**实现**:
- 确保满足 Polymarket 最小订单要求：
  - 最小 $1 USDC
  - 最小 5 shares
- 如果计算的订单小于最小值，自动提升到最小值
- 重新计算 size 以匹配新的 cost

**关键代码**:
```go
func sizeFromBudget(budget, price float64) float64 {
    const minOrderUSDC = 1.0
    const minOrderShares = 5.0
    
    // 计算初始size
    size := budget / price
    
    // 如果cost小于$1，提升到$1
    if actualCost < minOrderUSDC {
        actualCost = minOrderUSDC
        size = actualCost / price
    }
    
    // 如果size小于5 shares，提升到5
    if size < minOrderShares {
        size = minOrderShares
        actualCost = size * price
    }
    
    return size
}
```

#### 2. 市场关闭检测
**文件**: `internal/market/polymarket_trading.go`

**实现**:
- 在下单前快速检查市场是否关闭
- 检测404错误和"No orderbook exists"错误
- 立即跳过已关闭的市场，避免浪费资源

**关键代码**:
```go
func (p *Polymarket) checkMarketOpen(ctx context.Context, tokenID string) error {
    _, err := p.clobClient.GetOrderBook(checkCtx, tokenID, nil)
    if err != nil {
        errStr := err.Error()
        if strings.Contains(errStr, "404") || 
           strings.Contains(errStr, "No orderbook exists") {
            return fmt.Errorf("market closed or resolved: %w", err)
        }
    }
    return nil
}
```

### ✅ 优先级2：短期实施

#### 4. 动态滑点管理
**文件**: `internal/strategy/executor.go`

**实现**:
- 根据token价格动态调整滑点容忍度
- 低价token（<0.10）：允许200%滑点
- 高价token（>0.40）：只允许20%滑点
- 在价格计算中应用滑点限制

**关键代码**:
```go
func getMaxSlippage(price float64) float64 {
    switch {
    case price < 0.10:
        return 2.00 // 200%
    case price < 0.20:
        return 0.80 // 80%
    case price < 0.30:
        return 0.50 // 50%
    case price < 0.40:
        return 0.30 // 30%
    default:
        return 0.20 // 20%
    }
}
```
