# 简单阈值策略说明

## 策略概述

`simple_threshold` 策略是一个基于价格阈值的简单交易策略，通过 WebSocket 实时接收价格变化，当价格达到阈值时自动买入，并立即挂出止盈限价单。

## 策略规则

1. **买入条件**：
   - 当 YES 价格 ≥ 60 分（0.60）时，买入 YES
   - 当 NO 价格 ≥ 60 分（0.60）时，买入 NO
   - 价格使用 `best_ask`（买入时）或 `best_bid`（买入 NO 时）作为参考

2. **自动止盈**：
   - 买入后，立即挂出限价单卖出
   - 卖出价格 = 买入价格 + 3 分（0.03）
   - 例如：60 分买入，63 分卖出

3. **持仓管理**：
   - 策略会跟踪持仓状态
   - 如果已有持仓，不会重复买入
   - 周期切换时自动重置状态

## 配置方法

### 1. 在配置文件中启用策略

编辑 `config.yaml`：

```yaml
strategies:
  enabled:
    - "simple_threshold"  # 或使用 "simple"（别名）
```

### 2. 策略参数（代码中配置）

当前策略参数在代码中硬编码，可以通过修改 `internal/strategy/simple_threshold.go` 调整：

```go
buyThreshold: 0.60,  // 买入阈值（60 分）
profitTarget: 0.03,  // 止盈目标（3 分）
orderSize:    10.0,  // 订单大小
```

## 工作流程

```
WebSocket 价格更新
    ↓
事件总线 (EventMarketTick)
    ↓
Engine 处理事件
    ↓
Brain 生成 Intent
    ↓
OMS 调用策略执行器
    ↓
策略检查价格阈值
    ↓
如果价格 ≥ 60 分且无持仓 → 生成买入订单 + 卖出限价单
    ↓
OMS 执行订单
```

## 策略状态

策略维护以下状态：
- `entryPrice`: 入场价格
- `entrySide`: 入场方向（YES 或 NO）
- `hasPosition`: 是否持仓
- `pendingSellPrice`: 待挂卖出价格

## 注意事项

1. **价格单位**：策略使用小数表示价格（0.60 = 60 分）
2. **订单大小**：默认 10.0，可以根据需要调整
3. **周期重置**：每个 15 分钟周期开始时，策略状态会自动重置
4. **风险控制**：策略受 Engine 的风险控制机制约束（KillSwitch、Freeze 等）

## 示例场景

### 场景 1：YES 价格触发

1. WebSocket 收到价格更新：YES 价格 = 0.62
2. 策略检测到价格 ≥ 0.60，且当前无持仓
3. 生成订单：
   - 买入 YES @ 0.62（使用 best_ask）
   - 卖出限价单 @ 0.65（0.62 + 0.03）
4. OMS 执行订单

### 场景 2：NO 价格触发

1. WebSocket 收到价格更新：YES 价格 = 0.35（NO 价格 = 0.65）
2. 策略检测到 NO 价格 ≥ 0.60，且当前无持仓
3. 生成订单：
   - 买入 NO @ 0.65
   - 卖出限价单 @ 0.68（0.65 + 0.03）
4. OMS 执行订单

## 策略注册

策略在 `internal/strategy/simple_threshold_init.go` 中自动注册：

```go
func init() {
    RegisterStrategy("simple_threshold", NewSimpleThresholdStrategy())
    RegisterStrategy("simple", NewSimpleThresholdStrategy()) // 别名
}
```

## 扩展建议

如果需要更灵活的配置，可以考虑：

1. **配置文件支持**：将策略参数添加到配置文件
2. **多阈值支持**：支持不同的买入和卖出阈值
3. **动态调整**：根据市场波动动态调整止盈目标
4. **止损机制**：添加止损逻辑
