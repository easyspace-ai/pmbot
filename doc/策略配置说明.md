# 策略配置说明

## 简单阈值策略配置

`simple_threshold` 策略的所有参数现在都可以通过配置文件设置，无需修改代码。

### 配置示例

在 `config.yaml` 中配置：

```yaml
strategies:
  enabled:
    - "simple_threshold"
  simple_threshold:
    buy_threshold: 0.60  # 买入阈值（0.60 = 60分）
    profit_target: 0.03  # 止盈目标（0.03 = 3分）
    order_size: 10.0     # 订单大小
```

### 配置参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `buy_threshold` | float | 0.60 | 买入阈值，当价格达到此值时触发买入（0.60 = 60分） |
| `profit_target` | float | 0.03 | 止盈目标，买入后挂卖出单的价格增量（0.03 = 3分） |
| `order_size` | float | 10.0 | 订单大小（shares） |

### 配置优先级

配置加载优先级（高优先级覆盖低优先级）：

1. **环境变量**（如果设置）
   - `SIMPLE_THRESHOLD_BUY_THRESHOLD`
   - `SIMPLE_THRESHOLD_PROFIT_TARGET`
   - `SIMPLE_THRESHOLD_ORDER_SIZE`

2. **配置文件**（`config.yaml`）

3. **默认值**
   - `buy_threshold: 0.60`
   - `profit_target: 0.03`
   - `order_size: 10.0`

### 使用环境变量

也可以通过环境变量设置（优先级高于配置文件）：

```bash
export SIMPLE_THRESHOLD_BUY_THRESHOLD=0.65
export SIMPLE_THRESHOLD_PROFIT_TARGET=0.05
export SIMPLE_THRESHOLD_ORDER_SIZE=15.0
```

### 配置验证

启动时会显示加载的配置：

```
策略 simple_threshold 已加载并设置到 OMS (buy_threshold=0.60, profit_target=0.03, order_size=10.0)
```
