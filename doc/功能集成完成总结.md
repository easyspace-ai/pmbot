## 使用示例

### 基本使用（当前状态）

```go
// main.go - 当前实现
omsInstance := oms.New()
// OMS会自动使用简单逻辑（desiredOrder）

en := engine.New(
    log,
    engine.Config{BusBuffer: 4096},
    adapter,
    signals.New(),
    brain.New(),
    risk.New(),
    omsInstance,
    position.New(),
    audit.NopSink{},
)
```

### 启用策略执行器（可选）

如果需要订单簿深度分析和动态滑点管理：

```go
import "polymarket-btc-bot/internal/strategy"

// 创建策略执行器
executor := strategy.New()

// 设置到OMS
omsInstance := oms.New()
omsInstance.SetStrategy(executor)

en := engine.New(...)
```

## 性能改进

### 订单簿访问速度
- **之前**: 每次~200ms（API调用）
- **现在**: 首次~200ms，后续~50ms（缓存命中）

- **之前**: 尝试下单后才发现市场关闭
- **现在**: 下单前快速检测（2秒超时）
- **改进**: 避免无效API调用

### 时间追踪
- **开销**: <0.1ms per tick
- **价值**: 识别性能瓶颈，优化执行速度
