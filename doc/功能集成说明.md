# PMBot 功能集成说明

本文档说明已集成到 PMBot 的三个新功能：WebSocket 实时数据、YAML 配置和策略管理。

## 一、YAML 配置系统

### 1.1 功能概述

PMBot 现在支持通过 YAML 或 JSON 配置文件进行配置，同时保留环境变量的支持。配置优先级为：**环境变量 > 配置文件 > 默认值**。

### 1.2 使用方法

#### 创建配置文件

创建 `config.yaml` 文件（参考 `config.yaml.example`）：

```yaml
# 基础配置
log_level: "info"
log_file: "logs/combined.log"
log_by_cycle: true

# Polymarket 配置
polymarket:
  use_websocket: true  # 启用 WebSocket 实时数据
  base_url: "https://clob.polymarket.com"
  market_slug_regex: "^btc-updown-15m-\\d+$"

# 策略配置
strategies:
  enabled:
    - "simple"
```

#### 启动时指定配置文件

```bash
# 使用指定配置文件
go run cmd/bot/main.go -config config.yaml

# 使用默认配置文件（config.yaml）
go run cmd/bot/main.go
```

### 1.3 配置项说明

| 配置项 | 环境变量 | 说明 |
|--------|---------|------|
| `log_level` | `LOG_LEVEL` | 日志级别：debug, info, warn, error |
| `log_file` | `LOG_FILE` | 日志文件路径 |
| `log_by_cycle` | `LOG_BY_CYCLE` | 是否按周期命名日志文件 |
| `polymarket.use_websocket` | `POLY_USE_WEBSOCKET` | 是否使用 WebSocket（推荐 true） |
| `polymarket.base_url` | `POLY_CLOB_BASE_URL` | CLOB API 基础 URL |
| `polymarket.market_slug_regex` | `POLY_MARKET_SLUG_REGEX` | 市场 slug 正则表达式 |
| `strategies.enabled` | `ENABLED_STRATEGIES` | 启用的策略列表（逗号分隔） |

### 1.4 敏感信息处理

**重要**：钱包私钥等敏感信息建议使用环境变量，而不是配置文件：

```bash
export POLY_PRIVATE_KEY="your_private_key"
export POLY_FUNDER="your_funder_address"
```

配置文件中的钱包配置会被忽略，优先从环境变量读取。

## 二、WebSocket 实时数据

### 2.1 功能概述

PMBot 现在支持通过 WebSocket 实时接收市场数据，替代原有的 HTTP 轮询方式。WebSocket 提供：
- **低延迟**：实时价格更新（< 100ms）
- **高效率**：减少 HTTP 请求开销
- **自动重连**：连接断开时自动重连

### 2.2 启用 WebSocket

在配置文件中设置：

```yaml
polymarket:
  use_websocket: true  # 启用 WebSocket
  websocket_proxy: ""  # 可选：WebSocket 代理 URL
```

或使用环境变量：

```bash
export POLY_USE_WEBSOCKET=true
```

### 2.3 工作原理

1. **连接建立**：连接到 `wss://ws-subscriptions-clob.polymarket.com/ws/market`
2. **市场订阅**：订阅指定市场的 YES/NO token 价格变化
3. **事件发布**：收到价格更新后，通过事件总线发布到单线程引擎
4. **自动重连**：连接断开时自动重连（冷却期 15 秒）

### 2.4 与 HTTP 轮询的对比

| 特性 | WebSocket | HTTP 轮询 |
|------|-----------|-----------|
| 延迟 | < 100ms | 300ms+ |
| 效率 | 高（推送） | 低（轮询） |
| 资源消耗 | 低 | 中等 |
| 可靠性 | 自动重连 | 需要手动处理 |

### 2.5 注意事项

- **订单操作**：WebSocket 适配器仅用于接收市场数据，订单操作（PlaceOrder/CancelOrder）仍需要通过 HTTP API
- **混合模式**：当前版本 WebSocket 适配器不支持订单操作，如需交易功能，建议：
  - 使用 WebSocket 接收市场数据
  - 使用 HTTP 适配器进行订单操作（未来版本将支持混合模式）

## 三、策略管理系统

### 3.1 功能概述

PMBot 现在支持策略注册和动态加载，允许：
- **策略注册**：策略在 `init()` 函数中自动注册
- **策略选择**：通过配置文件选择启用的策略
- **策略扩展**：易于添加新策略

### 3.2 策略接口

策略需要实现 `oms.StrategyExecutor` 接口：

```go
type StrategyExecutor interface {
    Execute(tick types.MarketTick, intent types.Intent, pos struct {
        YesShares  float64
        NoShares   float64
        Confidence float64
    }) []OrderDecision
}
```

### 3.3 注册策略

在策略包的 `init()` 函数中注册：

```go
package my_strategy

import (
    "polymarket-btc-bot/internal/oms"
    "polymarket-btc-bot/internal/strategy"
    "polymarket-btc-bot/internal/types"
)

type MyStrategy struct {
    // 策略配置
}

func (s *MyStrategy) Execute(tick types.MarketTick, intent types.Intent, pos struct {
    YesShares  float64
    NoShares   float64
    Confidence float64
}) []oms.OrderDecision {
    // 策略逻辑
    return []oms.OrderDecision{
        {
            Side:   types.SideYes,
            Price:  0.65,
            Size:   10.0,
            Reason: "my_strategy",
        },
    }
}

func init() {
    strategy.RegisterStrategy("my_strategy", &MyStrategy{})
}
```

### 3.4 启用策略

在配置文件中指定：

```yaml
strategies:
  enabled:
    - "my_strategy"
```

或使用环境变量：

```bash
export ENABLED_STRATEGIES="my_strategy"
```

### 3.5 当前支持的策略

- **simple**：简单策略（默认，如果未指定策略）

### 3.6 策略执行流程

1. **Brain 生成 Intent**：根据市场信号和风险状态生成交易意图
2. **策略执行**：策略执行器将 Intent 转换为订单决策
3. **OMS 执行订单**：OMS 根据订单决策执行订单

## 四、使用示例

### 4.1 完整配置示例

```yaml
# config.yaml
log_level: "info"
log_file: "logs/combined.log"
log_by_cycle: true

proxy:
  host: "127.0.0.1"
  port: 15236

strategies:
  enabled:
    - "simple"

  use_websocket: true
  base_url: "https://clob.polymarket.com"
  market_slug_regex: "^btc-updown-15m-\\d+$"
  trading_enabled: false
```

```bash
# 设置环境变量（敏感信息）
export POLY_PRIVATE_KEY="your_private_key"
export POLY_FUNDER="your_funder_address"

# 启动机器人
go run cmd/bot/main.go -config config.yaml
```

## 五、架构说明

### 5.1 保持单线程架构

所有新功能都保持与 PMBot 单线程架构的兼容性：

- **WebSocket 适配器**：在独立 goroutine 中接收数据，通过事件总线发布到单线程引擎
- **策略系统**：策略执行在单线程引擎的事件处理循环中
- **配置系统**：配置在启动时加载，不影响运行时

### 5.2 事件流

```
WebSocket → 价格更新 → 事件总线 → 单线程引擎 → Brain → 策略 → OMS → 订单
```

## 七、故障排查

### 7.1 WebSocket 连接失败

- 检查代理配置是否正确
- 检查网络连接
- 查看日志中的错误信息

### 7.2 策略未加载

- 检查策略是否已注册（查看 `init()` 函数）
- 检查配置文件中策略名称是否正确
- 查看日志中的错误信息

### 7.3 配置加载失败

- 检查配置文件格式（YAML/JSON）
- 检查配置文件路径
- 查看日志中的错误信息
